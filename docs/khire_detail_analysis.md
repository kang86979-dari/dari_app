### CSS 잔존 원인
현재 정규식이 `.className { }` 패턴만 처리하고, **CSS keyframe 패턴**을 처리하지 못함:
```
50% { color:#fff; } 100% { color:#fff; } }
50% { color:#003194; } 100% { color:#003194; } }
90%{opacity:0;}99%{opacity:0;}100%{opacity:1;}}
```
`\d+%\s*\{` 형태는 `\.[\w-]+[^{]*\{` 정규식에 매칭되지 않음.

### 수정 방안
CSS 전처리 단계에 keyframe 퍼센트 패턴 제거 정규식 추가:
```dart
// CSS keyframe 퍼센트 블록 제거 (50% { color:#fff; } 등)
cleaned = cleaned.replaceAll(RegExp(r'\d+%\s*\{[^}]*\}'), '');
```
