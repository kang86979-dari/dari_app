## 종합 — 발견 사항 (우선순위순)

### 확정 버그 (수정 필요)
1. **[버그1·중] 마감 판정 경계 불일치** — `applied_job_provider.dart:39` `isBefore(DateTime.now())` (시각 비교). 홈 RPC·JobCard·상세는 날짜 단위 → **마감일이 오늘인 공고가 지원 내역에서만 "마감"** 처리. 수정: 날짜 단위 비교로 통일.
2. **[버그2·중] 메모 조회 실패 시 무반응** — `jobNotesProvider.future` await가 try 밖 (job_detail 994 / favorites / apply_history / my_memos 4곳). 오프라인에서 메모 탭 시 시트도 안내도 없음. 수정: try/catch + 실패 스낵바.
3. **[버그3·중] 로드 에러가 "없어요" 빈 화면으로 위장** — 지원 내역·내 메모의 error 분기가 `_empty()`. 기록이 있는데 없다고 보임. 수정: 기존 `error_retry` 위젯 재사용.

### 중요 의심 (수정 강력 권장)
4. **[중요1] 탈퇴 응답 유실 → 실패 루프** — 서버 삭제 성공+타임아웃 시 세션 잔존, 재시도가 계속 401 실패. 수정: catch에서 401이면 성공 간주(signOut+초기화).
5. **[중요2] 로컬 즐겨찾기 계정 간 공유** — 로그아웃/탈퇴 후 하트 잔존, 다른 계정에 이전 하트 노출. 즐겨찾기 서버화 작업에 "로그아웃 시 로컬 비움" 필수 포함.
