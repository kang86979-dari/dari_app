# K-HIRE 가입/로그인/지원 화면 캡처 기록

> ⚠️ **회원가입은 계정당 1회뿐** — 다시 못 하므로 각 화면을 빠짐없이 기록할 것.

## 캡처 환경
- **PC 크롬 + 모바일 에뮬레이션** (F12 → Ctrl+Shift+M → 갤럭시/아이폰 선택)
- 대상: `https://m.khire.co.kr`
- 이유: 고객은 폰에서 보지만, HTML 저장·검사는 PC가 확실. 모바일 뷰포트/UA라 고객 화면과 동일.

## 화면마다 3가지 기록
1. **스크린샷** (`NN_이름.png`) — 오버레이 안내용 (버튼/입력칸 위치)
2. **HTML 소스** (`NN_이름.html`) — 셀렉터용 (input의 name/id)
   - DevTools → Elements → `<html>` 우클릭 → Copy → **Copy outerHTML** → 저장
3. **URL** — 아래 표에 기록

## 파일명 규칙
`NN_단계이름` 2자리 번호 순서. 예: `01_지원레이어.png` / `01_지원레이어.html`
