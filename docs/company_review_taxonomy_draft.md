## MVP 범위 결정 (2026-09-02)
- **태그 위주 + 주제별 별점**으로 개발 (구조화 방식 = 기획서 D안).
- **자유서술(장점/단점 텍스트)은 이번 MVP에서 제외.**
- 결과 효과:
  - 태그·별점은 **16개 언어 1회 사전번역**으로 처리 → **런타임 번역 불필요**.
  - 번역 주체 결정(Claude/Google/NLLB) **보류** (자유서술 붙일 때 재논의).
    - NLLB-200은 크롤 서버(집 컴퓨터)에만 있고 HTTP API 미노출 + 홈 네트워크라 Supabase에서 상시 호출 불가 → 라이브 번역 경로로 부적합.
  - 자유서술 없음 → **명예훼손/스팸 리스크·모더레이션 부담 최소**.

## 별점 항목 (주제별 ★1~5) — 초안
1. 종합 (overall)
2. 급여·복지 (salary/benefits)
3. 워라밸 (work-life balance)
4. 근무환경 — 안전·기숙사 (environment)
5. 상사·관리 (management)
6. **외국인 대우 — 차별 여부 (foreigner treatment)** ← Dari 특화

## 주제별 태그(다중선택, 긍/부정) — 초안 예시
확정 아님. 나중에 주제별 긍/부정 세트를 16개 언어로 정리 예정.

| 주제 | 긍정 예 | 부정 예 |
|------|---------|---------|
| 급여·복지 | 급여 정시지급, 잔업수당 잘줌, 4대보험, 식사제공, 기숙사 제공 | 급여 체불 |
| 워라밸 | 정시퇴근, 휴가 자유 | 야근 많음, 주말근무 |
| 근무환경 | 안전장비 잘갖춤, 기숙사 깨끗 | 위험한 작업, 시설 낡음 |
| 상사·관리 | 사장 친절, 소통 원활 | 폭언 있음 |
| 외국인 대우 | 차별 없음, 통역·한국어 배려, 비자지원 | 차별 있음 |

## 태그 데이터 모델(예정)
- `review_tags` 마스터: id, category(주제), polarity(pos/neg/neutral), name_translations(jsonb 16개 언어), sort_order, is_active
- 리뷰의 선택 태그: `company_reviews.tag_ids`(배열) 또는 조인 테이블 `review_selected_tags`
- 별점: rating_overall + rating_salary/worklife/env/management/foreigner (int 1~5)
