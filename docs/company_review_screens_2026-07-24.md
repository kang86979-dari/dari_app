## 전체 화면 흐름

```
[기존 홈 / 공고상세 / 검색]
        │ 회사명·출처 탭
        ▼
  /company/:id  회사 프로필 ◀──── 회사 검색(2차)
    │   ├── 채용공고 N건 → /job/:id (기존)
    │   ├── 리뷰 리스트 (같은 화면 내)
    │   └── [리뷰 쓰기] 버튼
    │             │ 미로그인이면
    │             ▼
    │        /login (소셜: 구글·페북·애플)
    │             │ 성공 → 원래 자리 복귀
    │             ▼
    └──▶ /company/:id/review/write  리뷰 작성
                  │ 제출 → status=pending → AI 모더레이션(Edge Function)
                  ▼
            프로필로 복귀 (내 리뷰 pending 표시)

부가:
  /reviews/mine   내 리뷰(수정/삭제) — 설정 or 프로필에서 진입 (2차 가능)
  리뷰 신고 / 도움돼요 → 바텀시트·인라인 (별도 화면 아님)
```

### 기존 앱 진입점 연결
- **공고 상세** (`job_detail_screen`): 회사 정보/출처 영역에 `회사 리뷰 ★4.2 (23) ›` 진입 배너
- **공고 카드** (`job_card`): 회사명 탭 → 프로필 (카드에 평점 노출은 조인 부담 있어 2차 검토)

### 신규 라우트
```
/login
/company/:id
/company/:id/review/write
/reviews/mine        (2차 가능)
```

## 화면별 구성 & 기능

### 1. `/login` — 소셜 로그인
- **구성**: 로고 + 안내문("리뷰 작성·평가에는 로그인이 필요해요 / 리뷰는 익명으로 표시됩니다") + 소셜 버튼 **구글·페이스북·애플** + 약관/개인정보 동의 링크
- **기능**: `supabase_flutter.signInWithOAuth`, 성공 시 직전 화면으로 리다이렉트, 애플 버튼은 iOS에서만 노출 고려
- 다국어: 안내문 16개 언어

### 2. `/company/:id` — 회사 프로필 (핵심 화면)
위 → 아래 순서:
1. **상단바**: 뒤로가기 + 회사명 (+ 팔로우는 2차)
2. **광고 배너** (기존 패턴)
3. **평점 요약 카드**: 큰 평균 별점 + 별 그래픽 + 리뷰 수 + **별점 분포 막대(5→1)**
   - ⚠️ **최소 리뷰 수 미만이면 평점 숨김** + "아직 리뷰가 적어요, 첫 리뷰를 남겨보세요"
4. **세부 항목 평균**: 급여·복지 / 워라밸 / 근무환경 / 상사·관리 / **외국인 대우** (막대 5종)
5. 🔶 **태그 요약**(태그 채택 시): 많이 꼽힌 태그 상위 칩 ("야근 많음 12", "기숙사 제공 9"…)
6. **이 회사 채용 중 N건**: 기존 `job_card` 리스트 재사용
7. **리뷰 리스트**: 정렬(최신/평점/도움순 바텀시트) + 언어/재직상태 필터 + 무한스크롤
8. **하단 고정 [리뷰 쓰기]** 버튼

### 3. 리뷰 카드 (컴포넌트)
- 익명 헤더: 닉네임/**국적 플래그** + 재직상태(재직/퇴사) + 근무기간
- 종합 별점 + 작성일
- 장점 / 단점 (더보기 접힘)
- 🔶 선택 태그 칩(태그 채택 시)
- **원문 / 번역 토글** (상세화면 주소 토글과 동일 UX)
- 하단: **도움돼요 N** + **신고**(⋯)

### 4. `/company/:id/review/write` — 리뷰 작성
- 로그인 가드 / **1인 1회사 1리뷰** → 이미 있으면 수정 모드로 진입
- **구성(위→아래)**: 회사명(고정) → 종합 별점 → 세부 5종 별점 → 🔶 **태그 선택(카테고리별 다중)** → 재직상태·고용형태·근무기간·직무·비자(선택) → **장점/단점 텍스트(글자수 제한)** → 가이드라인 동의 → [제출]
- 🔶 **태그 위주 vs 자유서술 병행**에 따라 이 화면 비중이 크게 갈림 (미결정)
- 제출 → `status=pending` → Edge Function AI 모더레이션 → active/hidden/flagged

### 5. `/reviews/mine` — 내 리뷰 (2차 가능)
- 내가 쓴 리뷰 목록 + **상태 뱃지(검토중/게시/숨김)** + 수정/삭제

### 6. 신고 바텀시트 (화면 아님)
- 사유(허위/욕설/개인정보/명예훼손/스팸) + 상세 → `review_reports`

## 열린 논점 (결정 대기)

1. **회사 프로필 + 리뷰 리스트**: 한 화면(스크롤) vs 탭 분리(정보 / 리뷰)?
2. **작성 화면**: 태그 위주(빠름·다국어 유리) vs 자유서술 병행 — 남은 다국어 결정과 직결
3. **공고 카드에 평점 노출** 여부 (성능 트레이드오프 — 2차로 미룰지)
4. **내 리뷰 화면**을 MVP에 넣을지 2차로 뺄지
